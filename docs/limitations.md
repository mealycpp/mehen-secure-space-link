# Limitations

This repository is a research and demonstration artifact.

- The two-AUP secure-link dashboard extends the single-board MEHEN service demonstration for visualization and integration testing.
- The TRNG path is exercised through board-level smoke tests, not full SP 800-90B characterization.
- The demo is not a mission-certified secure communication protocol.
- Uplink authentication is inherited from the surrounding F′/ground infrastructure.
- Production deployment would require authentication, key-management policy, sustained workload tests, and mission safety review.
